⚠️ 발견·수정한 오류

FIX A 근로소득세액공제 한도 공식 — 계수 100배 오류

소득세법 제59조②
3호 (7천만~1.2억): 66만원 − [(총급여 − 7천만) × 1/2], 최소 50만원
4호 (1.2억 초과): 50만원 − [(총급여 − 1.2억) × 1/2], 최소 20만원

법정 계수는 1/2 (=0.5)인데 코드는 0.005로 100배 작게 적용 → 고소득 근로자의 공제한도 과대 → 세액 과소계산.

- limit = Math.max(660000 - (totalSalary - 70000000)  * 0.005, 500000);
+ limit = Math.max(660000 - (totalSalary - 70000000)  * 0.5,   500000);
- limit = Math.max(500000 - (totalSalary - 120000000) * 0.005, 200000);
+ limit = Math.max(500000 - (totalSalary - 120000000) * 0.5,   200000);

영향 계산기: 급여실수령액 · 세후세전역산 · 종합소득세 · 연말정산

FIX B 분양권 양도세율 — 2년 이상 보유 시 세율 오류

소득세법 제104조①1호 — 제55조 세율 (분양권의 경우에는 양도소득 과세표준의 100분의 60)
→ 분양권은 1년 이상이면 보유기간 무관 60% 단일세율 (1년 미만 70%)

코드는 "2년 이상 = 기본세율"로 처리하여 세액 과소계산. 60% 단일세율로 정정.

- else { calcTaxAmt = incomeTax(taxBase); rateDesc = '분양권 2년 이상: 기본세율'; }
+ else { calcTaxAmt = taxBase * 0.60;     rateDesc = '분양권 2년 이상: 60%'; }

추가로 2026 양도세 계산기의 "무주택 단일 분양권(2년↑) → 기본세율" 예외 처리도 제거(법령상 60% 고정).

FIX C 비사업용 토지 단기 양도세율 — 자산 구분 오류

소득세법 제104조① — 3호(1년 미만): 토지·건물 50% (주택·조합원입주권·분양권만 70%)
2호(1~2년): 토지·건물 40% (주택 등만 60%)

비사업용 토지는 "토지"이므로 단기 양도세율은 50%/40%인데, 코드는 주택용 단기율(70%/60%)을 잘못 적용. 같은 파일의 일반 토지·건물('commercial')은 50%/40%로 올바르게 처리돼 있어 분기 오류로 확인.

- if(holdYrs<1){ ... taxBase*0.70; '비사업용토지 1년 미만: 70%' }
+ if(holdYrs<1){ ... taxBase*0.50; '비사업용토지 1년 미만: 50%' }
- else if(holdYrs<2){ ... taxBase*0.60; '비사업용토지 1~2년: 60%' }
+ else if(holdYrs<2){ ... taxBase*0.40; '비사업용토지 1~2년: 40%' }

13개 파일에 동일 적용. (참고: §104④상 2년 미만 비사업용 토지는 단기율과 "기본세율+10%p" 중 큰 세액 적용 — 본 계산기는 단기율로 단순화.)
