데이터 백업 · 복원 · 정리

세무 도구에 입력한 내용(업무판 거래처, 보관한 계약서·CMS 신청서, 서명, 계산기 입력값 등)은 이 기기의 브라우저에만 저장됩니다. 브라우저 데이터를 지우거나 PC를 바꾸면 사라지므로, 이 화면에서 파일로 백업해 두고 새 PC에서 복원하십시오. PC 브라우저·휴대폰·앱은 저장소가 서로 달라 기기마다 따로 백업합니다.

이 기기에 저장된 항목

개인정보 주민번호·계좌·연락처가 들어 있을 수 있음 · 비밀값 사무소 확인 코드·AI API 키

② 복원 — 백업 파일 불러오기

개인정보가 들 수 있는 항목만 지웁니다(업무판·계약서·CMS 보관분·간편 포털 신청 기록 등). 계산기 입력값과 화면 설정은 남깁니다. 지우기 전에 필요하면 ①로 백업하십시오.
